# TYLER TV V8 | Five Worlds

Single-file, offline-capable browser dashboard for Bauhn webOS Hub and mobile browsers.

## What's new
- Five interactive guide worlds: Luna (adventures), Raven (planning), Pixie (content), Blaze (reset timer), Nova (opportunity checks)
- Guide rename and local-only persistence
- Save mini-tool results back into Vision Board cards
- Your photos and Genius Brigade branding remain separate from the guides
- All prior sections from V7 are retained

## Run
Open `index.html` in a browser, or deploy the folder to GitHub Pages.
Github Pages hosting has not yet been deployed.

## Important
The five interactive worlds use built-in templates, not a connected conversational AI. Photos and cards are saved on the individual device/browser. Use backup/restore when moving between files/devices. Embedded streaming playback depends on the browser's compatibility.

## Privacy
There are no API keys, login data or streaming credentials embedded in the project. The After Hours toggle is only a theme selection and starts off on reload, not an access-control system.
